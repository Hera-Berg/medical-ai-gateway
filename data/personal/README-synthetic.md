# Synthetic patient record (placeholder)

`synthetic-patient-001.pdf` is generated by `scripts/seed.py` and
is entirely fictional. No real PHI ever exists in this project.

Planned contents (tuned for the Type 2 diabetes demo so the cross-corpus
comparison against NICE NG28 produces a concrete numeric match):

- Name: "SYNTHETIC PATIENT 001 — NOT A REAL PERSON"
- HbA1c, fasting glucose, BMI, BP
- Current medications (e.g. metformin)
- A couple of comorbidities
  The values are chosen so that, e.g., the recorded HbA1c sits above the NG28
  target of 48 mmol/mol and near/above the 58 mmol/mol escalation trigger —
  making the "your labs vs the guideline" demo land clearly.
